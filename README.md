# 🌾 Agro Smart Farming System

A full-stack smart farming web application that helps farmers make better agricultural decisions through crop recommendations and real-time weather information.

## 🚀 Features

### 🔐 User Authentication
- User Registration
- User Login
- JWT Authentication
- Secure Password Storage

### 🌦 Weather Information
- Real-time weather updates
- Temperature
- Humidity
- Wind Speed
- Pressure
- Sunrise and Sunset timings

### 🌱 Crop Recommendation
- Soil-based crop suggestions
- Fertilizer recommendations
- Profit estimation
- Seasonal recommendations

### 📊 Farmer Dashboard
- Weather overview
- Crop recommendations
- Easy-to-use interface

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Ashwath-L/AgroSmart-Smart-Farming-System.git
```

### Navigate to Project

```bash
cd AgroSmart-Smart-Farming-System
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
OPENWEATHER_API_KEY=your_api_key
```

### Run Application

```bash
npm start
```

Server will run on:

```text
http://localhost:5000
```
